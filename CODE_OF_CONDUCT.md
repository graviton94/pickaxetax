# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and critique ideas and numbers, not people. Disagreement about methodology is welcome and is how the index gets better. Harassment is not.

Report problems privately through a [GitHub security advisory](https://github.com/graviton94/pickaxetax/security/advisories/new) (it reaches the maintainers only) or by contacting a maintainer directly.
