# 판정자 안내 (한 장)

AI 에이전트와의 대화 기록에서 낭비가 있었는지, 지시 하나씩 판정해 주시는 일입니다. 계정이 필요 없고, 받은 파일은
브라우저 탭 밖으로 나가지 않습니다(이 페이지는 어떤 서버로도 데이터를 보내지 않게 막혀 있습니다).

## 받는 것

- **판정 꾸러미 파일** (`….json`): 데이터 주인의 대화 일부를 발췌한 파일입니다. **다른 사람에게 보내거나 올리지 말고,
  판정이 끝나면 지워 주세요.**
- **판정자 코드**: A, B 같은 글자 하나. 데이터 주인이 정해 드립니다.

## 하는 순서

1. 판정 페이지를 엽니다: <https://graviton94.github.io/pickaxetax/label.html>
   (휴대폰에서도 됩니다. 메신저로 받은 꾸러미 파일은 먼저 휴대폰에 저장합니다. 아이폰은 공유 → '파일에 저장', 안드로이드는
   다운로드. 그다음 2번에서 그 파일을 고릅니다. 언어는 오른쪽 위 🌐에서 바꿀 수 있습니다.)
2. **판정 꾸러미 파일**에서 받은 파일을 고릅니다.
3. **판정자 코드**를 적습니다.
4. **단계**는 처음엔 **연습**을 고르고 **시작**을 누릅니다.
5. 항목마다 지시(사용자가 한 말), 에이전트가 한 일(도구 호출 목록), 마지막 응답을 읽고,
   - 여덟 갈래마다 **있음 / 없음 / 모름** 중 하나를 고릅니다. 화면에 근거가 없으면 **모름**입니다.
   - 한 낭비가 여러 갈래에 걸치면 **위쪽 갈래에만** 표시합니다.
   - 마지막으로 **결과가 요청을 충족했는지**(충족 / 일부 / 못 함 / 모름)를 고릅니다.
6. 다 하면 **판정 파일 내려받기**를 눌러, 내려받은 파일을 데이터 주인에게 보냅니다(휴대폰에서는 '파일' 앱이나 다운로드 폴더에 저장되니, 메신저에서 그 파일을 첨부합니다).
   이 파일에는 항목 번호와 선택만 들어 있고 대화 원문은 없습니다.
7. 연습이 끝나면 데이터 주인과 해석이 달랐던 항목을 함께 봅니다. 그다음 **본 판정**을 같은 방법으로 합니다.

진행 상황은 브라우저에 저장되므로 중간에 닫았다가 이어서 해도 됩니다.

## 여덟 갈래 (요약)

| 갈래 | 이런 것 |
|---|---|
| W1 중복 | 같은 일을 같은 결과로 다시 함 (바뀌지 않은 파일을 다시 읽기, 같은 페이지 두 번) |
| W2 실패·재시도 | 오류가 난 호출, 같은 실패의 반복, 실패를 수습하느라 다시 읽은 것 |
| W3 협업 손실 | 엉뚱한 곳으로 보낸 인계, 거절되거나 버려진 위임, 아무도 읽지 않은 하위 에이전트 결과 |
| W4 버린 산출물 | 쓰고 나서 지우거나 통째로 바꾼 것, 사용자가 "아니 그거 말고"라고 한 답 |
| W5 묵은 맥락 | 이미 끝난 지시의 내용을, 다시 쓰지도 않으면서 계속 싣고 다님 |
| W6 캐시 재작성 | 이미 처리한 맥락을 처음부터 다시 처리함 (세션 재개, 모델 변경, 캐시 만료) |
| W7 요청하지 않은 일 | 요청하지 않았고 쓰지도 않은 일 (하나를 부탁했는데 열 개를 만듦) |
| W8 과탐색 | 결과에 쓰이지 않은 읽기와 검색 (서른 개 파일을 읽고 세 개로 요약) |

**낭비가 아닌 것:** 매 호출에 필요한 기본 설정, 결과에 쓰인 탐색, 테스트와 검증(통과했더라도), 사람이 생각한 시간.

전체 기준: [`waste-codebook-v1.md`](waste-codebook-v1.md) (영어)

## 공개되는 것

판정 파일(항목 번호와 선택), 두 사람의 일치도, 엇갈린 항목 번호와 어떻게 합의했는지. 판정자는 A, B로만 표기하고,
원하시면 이름을 밝힙니다. 꾸러미와 대화 원문은 공개하지 않습니다.
