## 관찰 (기술만, 해석 없음)
1. 출력은 전체 토큰의 0.26%이고, 입력의 99%는 캐시 읽기다.
2. 상위 1개 세션이 입력의 57.2%, 상위 2개가 72.4%를 차지한다.
3. 세션 12개 중 11개는 휴대폰(android)에서 시작했다.
4. 입력이 큰 세션일수록 출력 1토큰당 읽은 양이 많다(스피어만 ρ = 0.76, n = 10).
