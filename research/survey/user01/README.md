## 관찰 (기술만, 해석 없음)
1. 출력은 전체 토큰의 0.26%이고, 입력의 99%는 캐시 읽기다.
2. 상위 1개 세션이 입력의 57.2%, 상위 2개가 72.4%를 차지한다.
3. 세션 12개 중 11개는 휴대폰(android)에서 시작했다.
4. 입력이 큰 세션일수록 출력 1토큰당 읽은 양이 많다(스피어만 ρ = 0.76, n = 10).
5. 며칠씩 이어진 세션이 많다(5일 이상 3개). 가장 큰 세션은 5.3일 동안 산출물(아티팩트) 64개를 만들었다.

세션별 값: `cloud-sessions.json`.

## 주의: 1층 합계는 하한일 수 있다

S08을 2층(이벤트 기록)으로 다시 재 보니, 호출별 입력의 합이 19,233,919로, 세션 목록의 사용량(7,253,135)의 약 2.7배였다. S01은 두 원천이 일치했다(로컬 기록과 세션 목록의 차이는 측정 시각 차이로 설명된다). 오래된 세션의 세션 목록 사용량은 일부 구간만 담고 있을 수 있으므로, **1층의 39.5억은 하한**으로 읽는다. 세션마다 2층으로 확인해 갈 때 이 표를 고친다.
