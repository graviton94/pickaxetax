Table 1 · Waste codebook v1

Waste = tokens that could have been removed without changing the result

CategoryWhat counts as wasteCompared againstJudged by
W1 DuplicationThe same work redone with the same result (re-reading an unchanged file, fetching the same data again)Done onceMachine
W2 Failure, retryErrored or aborted calls, repeated identical failures, context re-read to recoverThe successful path onlyMachine, rule
W3 Coordination lossHand-offs sent to the wrong place, refused or abandoned delegation, sub-agent output nobody read, polling with no changeRouted right the first timeMachine, rule
W4 Discarded outputFiles or drafts deleted or replaced wholesale before use, rejected answersOnly the kept outputRule, judgment
W5 Stale contextContext carried over from a finished instruction and never used againA fresh context holding only what is used laterRule
W6 Cache churnWriting the same prefix to the cache again after a resume, model switch or expiryOne write per prefixMachine
W7 Unrequested workWork nobody asked for and nobody usedOnly the requested workJudgment
W8 Over-explorationReads and searches the result did not draw on (sub-agents included)Only the exploration the result usedJudgment
Not wasteThe base every call needs · exploration the result used · verification such as tests (reported separately) OverlapsThe higher category takes them. No token is counted twice. UnitsRaw tokens and price-weighted tokens (cache reads at 0.1×), side by side.

How it is judged: start from a floor nobody can dispute

Machine

Decided from the logs alone. No human interpretation.W1 · W2 errors · W3 misrouting · W6Exact count = the floor

Rule

A rule applied by code, checked by two people labeling a sample of 200 instructions without seeing each other’s labels.W2 retries · W3 · W4 · W5Only if κ ≥ 0.70 per category: corrected estimate + CI

Judgment

Categories that need to know what was wanted are judged by people on the same sample.W4 rejected answers · W7 · W8Sample share + CI
↓
The result is a range, not one numberFloor: the sum of machine-judged waste (beyond dispute)
Ceiling: machine + rule + judgment upper bounds
A category that fails validation is reported as “not measured”, never as zero.

The criteria were committed before any data was judged; the commit is their timestamp. Changing them makes a new version, and every result names the version it used.
