## Post (English)

#AntiTokenMaxing · Chapter 9/10

How much of the AI compute that's been built actually produces value? Nobody publishes that number. We're building the index that does.

The Compute Bubble Index puts two kinds of numbers on one page for the first time.

From the top: money. AI infrastructure spending against AI revenue, using primary sources only, every number dated and graded as measured, reported or estimated.

From the bottom: measurements. How much compute real usage needed, in three gaps:
• Is the hardware actually running?
• Does the model compute only as much as the task needs?
• Did the request need that computation at all?

The bottom half can only come from users. So contributing is one click, with no account: after an analysis in the web app, press "Contribute anonymously". You see the exact JSON before it's sent: structure and counts, no text. Topic words are off by default and are only published once at least 3 independent contributions share them.

The data is open (ODbL), so anyone can recompute every number, including the people who disagree with it.
